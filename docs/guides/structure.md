# VWAP, CHoCH, BOS, order blocks and FVG

On Stock detail, use the Structure, VWAP, Order block and Fair value gaps controls to isolate an overlay. CHoCH and BOS mark changes or breaks in detected swing structure.

VWAP requires cumulative traded volume. Boxes mark algorithmically detected zones. An empty overlay means that this interval has no qualifying data or pattern.
