# Monte Carlo Time Machine

Open Time Machine to inspect target-first, stop-first and neither outcomes across 10,000 simulated paths. Use the custom form for your own symbol, entry, stop, target and CALL/PUT direction.

Paths reuse available historical observations. Underlying bars cannot reproduce an option premium. Missing history can prevent a result.
