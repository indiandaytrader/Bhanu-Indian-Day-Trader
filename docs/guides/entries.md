# Entry, stop, target and risk gate

Use the ORB or Levels breakdown to inspect entry, structural stop and target. The default target uses twice the initial risk distance.

Read PASS/BLOCK and the reason before evaluating a paper setup. Targets, stops and 15:15 reminders are planning outputs. The dashboard has no live order route.
