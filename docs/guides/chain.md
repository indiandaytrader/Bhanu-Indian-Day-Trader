# Option chain, OI, PCR and max pain

Open Option Chain, choose the index and an offered expiry, then Apply. The table is centered around ATM. Scroll sideways on a phone to see both legs.

OI totals, PCR and max pain use the whole selected expiry. Read the source and receipt timestamps. A retained snapshot can remain visible after an update fails.
