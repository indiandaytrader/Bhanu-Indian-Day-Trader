# Index dashboard and feed status

Open the home page. The three tiles show NIFTY 50, BANK NIFTY and SENSEX. Select a tile for its stock detail view.

The two-second interval is a polling cadence during the configured session. Read the source timestamp and stale or unavailable messages before interpreting a price. A newly received response can contain an older price.
