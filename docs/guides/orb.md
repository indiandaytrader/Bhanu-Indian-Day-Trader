# Opening-range scanner

Open ORB Scanner after 09:30 IST. The opening range uses the 09:15, 09:20 and 09:25 five-minute bars. A completed close outside the range triggers a directional setup.

Read the breakout time, range and breakdown together. CALL and PUT are directional labels. Check the source date if the scan is delayed.
