# Candles, EMA and volume

Select an index tile or stock link. Choose a timeframe, toggle EMA 20, and read the last-bar timestamp. EMA needs at least 20 closes.

Volume bars use reported volume. If the feed has no usable volume, the control is disabled. Index volume and VWAP can be unavailable.
