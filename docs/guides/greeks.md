# IV and Greeks

On the chain compare feed IV and model IV. Read delta, gamma, theta per day and vega per one volatility point for each leg.

Model IV inverts last traded premium using spot, strike and time to 15:30 IST expiry, zero interest and zero dividends. A missing timestamp, invalid premium or expired contract produces a dash.
